# 誤解を避けるための編集メモ

| 避ける言い方 | 代わりに書くこと |
| --- | --- |
| 「token は単語」 | token は tokenizer が文字列を分割して得る ID の単位であり、単語と一致するとは限らない。 |
| 「embedding の各次元には意味ラベルがある」 | embedding は学習された座標であり、個々の次元に安定した人間向け意味を期待しない。 |
| 「head は文法担当」 | head は別々の学習済み投影空間である。観察できる傾向を固定の役割として一般化しない。 |
| 「attention はモデルの説明そのもの」 | attention weight は計算の中間量であり、推論全体の万能な説明ではない。 |
| 「softmax の値は確信度」 | softmax は与えられた logits を相対的な重みに変換する。校正された確率や認識論的確信を自動で意味しない。 |
| 「LLM の能力は Transformer だけで決まる」 | architecture、学習データ、訓練、post-training、検索、ツール、agent 制御は別レイヤーである。 |
| 「表示した attention 図は実モデルの内部」 | 教材の矩形・重みは、明記しない限り小さな例または教育用の計算結果である。 |
