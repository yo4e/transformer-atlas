# 編集・技術 QA チェックリスト

各章を公開する前に、次の問いを確認する。

- [ ] 初出の数式記号、ベクトル、行列、転置、指数、確率、微分の語を本文で定義したか。
- [ ] その概念が必要になる理由を、記号の前に説明したか。
- [ ] 例の tensor shape は、コードと数式の両方で一致するか。
- [ ] 例示・教育用簡略化・実モデルの事実を区別したか。
- [ ] 比喩の後に、実際の計算機構へ戻ったか。
- [ ] token、embedding、attention、logit、probability の用語を一貫して使ったか。
- [ ] 図は色だけに意味を預けず、ラベル・線種・パターンも使ったか。
- [ ] 対話部品は初期状態だけでも理解でき、キーボードで操作できるか。
- [ ] 引用先が一次資料または公式資料で、主張の範囲を支えているか。
- [ ] 前後章・数学ページ・実装箇所へのリンクに切れがないか。
