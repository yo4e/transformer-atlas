# Logits と次 token 予測

**問題提起 — なぜ「最後の数値変換」が必要か**

文章をつくるモデルは、ある時点で「次に来るべき語（正確にはトークン）」の候補を数百から数十万通り持っています。モデルの内部で扱われるのは連続的な数（ベクトル）であり、候補の数だけ並んだ「どれがどれくらい望ましいか」を直接持っているわけではありません。したがって、モデルは「最後の一手」として、今ある内部の数ベクトルを各候補トークンごとの「点数」に変え、その点数を確率に変え、そこから選択（最も高いものを取るか、確率に従ってサンプリングするか）をします。この「ベクトル → 候補ごとの点数 → 確率 → 選択」の道筋がないと、有限の語彙集合から次のトークンを選べません。

この章では、その「最後の数値変換」がどのように定義され、どの数が学習パラメータでどの数がその時点の活性（activation）なのかをどう区別するか、さらに確率と選択結果が別物であることを、具体例と数式、短いコードを使って確実に説明します。なお、示す小さな数値例は教材上の説明のためのものであり、実際の大規模モデルの内部状態を示すものではありません。

**直感とその限界（有用なイメージと注意）**

直感的には、内部ベクトルは「今の文脈の要約」で、語彙ごとの重み行列は「その要約を各語彙にどれだけ結び付けるかのルール」です。ベクトルと重み行列の掛け算は「要約を各語彙に対して評価する」操作と見なせます。得られた未正規化の値（logit）は「語彙ごとの好感度スコア」のように扱え、softmaxで正規化すると合計が1の確率分布になります。

ただし注意点が二つあります。第一に、得られたスコアは確率そのものではありません（logitは未正規化スコア）。第二に、内部ベクトルと重み行列の掛け算は線形操作であるため、直感的に「語彙ごとに独立に判断している」と思うのは誤りです。重み行列の行は共通の基底（hidden 次元）に投影されるため、ある語のスコアの変化は他の語のスコアと相関し得ます。つまり「ある語に高いスコアが付く＝他の語は必然的に低くなる」と単純には結びつきません（softmaxという正規化の影響を別にすれば、線形部分は各語の相関を反映します）。

**数値オブジェクトの分類 — パラメータと入力・活性の違い**

ここで扱う数値は少なくとも次の3種類に分けて考えます。

- 学習されるパラメータ（例: 出力用の重み行列 W_vocab やバイアス b_vocab）。これらは訓練データと最適化手法によって変化する「固定されたルール」です。
- 入力に由来する活性（activation、ここでは最後の hidden vector h）。これはモデルがある文脈を見てその場で産出する値で、推論ごとに異なります。
- 中間的に計算されるスコア（logits）や確率。これらは W_vocab と h から算出される「一時的な数値」で、選択の根拠になりますが学習パラメータそのものではありません。

混同しないよう常に名前をつけて扱います。

**具体例（必須）：h=[1,2] と W_vocab から logits [2,1,3,-1] を得る場合**

まず、例の定義を明示します。隠れベクトル（最後の hidden vector）を h = [1, 2] とします。語彙数は 4 とし、出力重み行列 W_vocab は各行が対応する語彙の線形係数を表すものとします。行列の各行 w_i を次のように取ると、内積で下の logit が得られます。

W_vocab（各行が語彙の係数）:
- w_0 = [0, 1]  → w_0 · h = 0*1 + 1*2 = 2
- w_1 = [1, 0]  → w_1 · h = 1*1 + 0*2 = 1
- w_2 = [1, 1]  → w_2 · h = 1*1 + 1*2 = 3
- w_3 = [-1, 0] → w_3 · h = -1*1 + 0*2 = -1

これをまとめると logits = [2, 1, 3, -1]（バイアスはゼロとする簡単化）になります。次にこの logits を softmax で確率に変換します。softmax の定義は次の通りです（後で数式で示しますが、ここでは数値計算を示します）。

各要素の指数関数（自然対数の底 e を用いる）:
- e^{2}   ≈ 7.38905609893
- e^{1}   ≈ 2.71828182846
- e^{3}   ≈ 20.0855369232
- e^{-1}  ≈ 0.36787944117

これらの合計は約 30.5607542918 です。したがって softmax 確率は
- p_0 ≈ 7.3890561 / 30.5607543 ≈ 0.2417
- p_1 ≈ 2.7182818 / 30.5607543 ≈ 0.0890
- p_2 ≈ 20.0855369 / 30.5607543 ≈ 0.6572
- p_3 ≈ 0.3678794 / 30.5607543 ≈ 0.0121

最も確率が高いのは p_2（インデックス 2、ゼロ始まり）であり、argmax を取れば語彙の 3 番目の要素が選ばれます。一方で確率に従ってサンプリングすれば低確率の語が出る可能性もあります。ここで示した数値は教材用の小さな例で、実際のモデルの内部状態を反映するものではありません。

（注）上のインデックスはゼロ始まりで示しています。実装上は 0,1,2,3 と考えることが多い点に注意してください。

**数式での定義 — 記号の説明と行列積の意味**

ここで数式をまとめます。まず記号の定義を普通の言葉で示します。

- V: 語彙の総数（vocabulary size）。この章の具体例では V = 4。
- d: 隠れベクトル（hidden）の次元（hidden dimensionality）。例では d = 2。
- h ∈ R^d: モデルがその時点で出力した隠れベクトル（活性）。列ベクトルと考える。
- W ∈ R^{V × d}: 出力重み行列。各行 w_i（長さ d）は語彙 i に対応する線形係数。
- b ∈ R^V: 出力バイアス（ある場合）。この章の簡単化例では b = 0。
- logits ℓ ∈ R^V: 各語彙についての未正規化スコア。ℓ = W h + b。
- softmax(ℓ)_i = exp(ℓ_i) / Σ_j exp(ℓ_j): ℓ を確率分布に変換する関数。
- argmax(ℓ) = argmax_i ℓ_i: もっともスコアの高い語彙のインデックス。

行列積の意味を普通の言葉で表すと、「W の各行（語彙ごとの係数）と隠れベクトル h の内積を取り、その結果を各語彙のスコアとする」ということです。h はその時点の情報の圧縮（文脈の要約）で、W はその要約を語彙ごとの好み（線形スコア）に変換する定数です。

形式的に：
ℓ = W h + b
p = softmax(ℓ)

ここで ℓ の i 成分は ℓ_i = w_i · h + b_i（w_i は W の i 行）です。

softmax の重要性について短く触れると、softmax は指数関数を使って大きな差を拡大するため、相対的に強く支持される候補がますます高い確率を得やすくなります。また softmax は定数を足しても結果が変わらない（exp(ℓ_i + c) / Σ_j exp(ℓ_j + c) = exp(ℓ_i) / Σ_j exp(ℓ_j)）という性質があります。したがって logits の絶対値よりも相対的な差が重要です。

**透明な短い Python コード例**

以下は上の数式・数値例をそのまま再現する NumPy コードです。変数名は数式と対応しています。

```python
import numpy as np

h = np.array([1.0, 2.0])           # 隠れベクトル h (d=2)
W = np.array([[0.0, 1.0],          # W の行は w_0, w_1, w_2, w_3
              [1.0, 0.0],
              [1.0, 1.0],
              [-1.0, 0.0]])         # shape: (V=4, d=2)
b = np.zeros(4)                    # バイアスはゼロにする

# logits の計算
logits = W.dot(h) + b              # shape: (4,)
# softmax の計算（数値安定化のために最大値を引く）
def softmax(x):
    x_max = np.max(x)
    exps = np.exp(x - x_max)
    return exps / exps.sum()

probs = softmax(logits)
argmax_index = int(np.argmax(logits))  # 0-based index

print("logits:", logits)    # [ 2.  1.  3. -1.]
print("probs:", probs)      # ≈ [0.2417, 0.0890, 0.6572, 0.0121]
print("argmax:", argmax_index)  # 2
```

このコードは W·h の順序、shape、softmax の数値安定化（最大値を引く）まで示しています。実装では logits にスケーリングや温度（temperature）を掛ける操作を入れることがありますが、基本はこの流れです。

**モデル全体内での前後の処理 — 前段と後段の関係**

Transformer 系モデルの（一例としての）流れを簡潔に整理します。

- 入力段階: 各トークンはまず整数のトークンIDに変換され、その ID を使って入力埋め込み（embedding）から d 次元ベクトルに置き換えられます。位置情報を足す処理もここで入る。
- 計算段階: 埋め込みは複数の層（自己注意 + フィードフォワード等）を経て文脈に応じた隠れベクトル h を得ます。Decoder-only（GPT 型）では各位置について因果マスクを使い、左側の文脈のみを使って逐次的に h を計算します。
- 出力段階（この章の内容）: 得られた h を W_vocab で線形射影し logits を得て、softmax で確率分布を作り、最終的に argmax や確率的サンプリングで次トークンを決めます。

実装上、出力重み W_vocab は入力の埋め込み行列と転置を共有（weight tying）していることが多く、これは語彙ごとの初期的な意味付けを統一する効果があります。ただしこれは設計上の選択であって必須ではありません。

**現実の大規模モデルとの接続と注意点**

実際の大規模言語モデルでは、語彙数は数万〜数十万で、隠れ次元 d も数百〜数千になります。ここで示した小さな行列は説明のための単純化です。重要な点は次の通りです。

- 実際の W_vocab は非常に大きく学習されるパラメータです。メモリや計算コストの観点から、転置共有やスパース化などの工夫が用いられることがあります（例: モデルの変種である MoE など）。
- logits の絶対値や分布の形は学習や正則化、温度などで変化します。確率の「信頼度」は必ずしもモデルが正しい確率を表しているとは限らない（キャリブレーションの問題）。
- トークンは必ずしも「単語」と同義ではありません。現代のモデルは BPE やサブワード単位を使うことが多く、語彙は文字や部分語の混合です（参照: Sennrich et al.）。

**よくある誤解の訂正（少なくとも一つ）**

誤解: 「attention weights（自己注意の重み）はモデルが『ここを注目している』という明確かつ人間的な証拠である。」

訂正: Attention の出力は確かに入力位置ごとの加重和ですが、注意重みそのものが直接的な因果説明や人間の注目と一致するとは限りません。注意は学習された線形演算と正則化の結果であり、複雑な相互作用（残差接続、層正規化、フィードフォワードなど）を経た後の表現を決定します。したがって「attention weight を見ればモデルが人間のように何を注目しているか分かる」と単純に結論づけるのは危険です。

別のよくある誤解: 「logits を見れば確率が分かる」。logits 自体は確率ではありません。softmax によって初めて確率になり、さらに選択（argmaxやサンプリング）とは別の操作です。

**学習における振る舞い（簡潔に）**

学習中、W_vocab は誤差逆伝播で更新されます。損失は通常、モデルが生成した確率分布 p と正解トークンのワンホット表現を比べる交差エントロピー（cross-entropy）です。PyTorch 等の実装では torch.nn.Embedding と torch.nn.CrossEntropyLoss の組み合わせが典型的です。なお CrossEntropyLoss は内部で softmax と負の対数を組み合わせた計算を効率的に行うため、実装上は logits を直接与えます（softmax を外で計算する必要はありません）。

**章のまとめ — この章で説明できること**

読者は次を説明できるはずです。
- 隠れベクトル h と学習パラメータ W（および b）がどのように掛け合わされて各語彙の未正規化スコア（logits）を生むか。
- logits、softmax 確率、argmax（またはサンプリング）は別物であり、それぞれの役割が何か。
- W の行が語彙に対応する線形係数であること、h は推論時に得られる活性であること、これらを混同しないこと。
- 小さな数値例（h=[1,2] 等）は説明のための簡易化であり、実モデルの値ではないこと。

確認問題（解答は別途用意してください）
1. 次の logits = [0, 0, 0] の場合に softmax による確率分布と argmax の結果はどうなるか。直感的な説明を付けよ。
2. 隠れベクトル h = [2, -1]、W の一行が w = [1, 3]、バイアス b = -2 であるとき、その行の logit を計算し、logits が [1, 0, 2] の場合の softmax 確率を求めよ。
