# Residual connection と normalization

問題提起 — 深く積み重ねたネットワークで何が困るのか、名前はまだ言わない

深く層を重ねると、学習が急に難しくなる実務的な問題が現れます。入力信号（ある層の出力）が次の層に伝わるうちに、数値が非常に小さくなったり非常に大きくなったりして、重みを更新するための勾配がほとんど消えたり爆発したりします。あるいは各層の内部で算出される中間値の「大きさ（スケール）」や「ばらつき（分布）」が層ごとに変わり、下流の層がそれに合わせて再学習し続けなければならないため収束が遅くなります。さらに、深い積層は「今の層で入力をそのまま保持しておきたい」ようなケースでも、情報が薄れてしまいがちです。

これらの困りごとを放置すると、モデルの学習が安定しない、学習時間が長くなる、性能が出ない、という形で現れます。ここで扱う仕組みは、こうした問題に実務的に対処するために設計されています。最初に直感を提示し、その後で数式・実例・簡単なコードで透明に説明します。仕組みの「名前」は初めに出していませんが、後半でそれらの正式な式と実装を示します。

直感とその限界（文字どおり受け取ってはいけない点）

直感A — 「元の入力をそのまま残す道があれば、情報が消えにくくなる」
これは文字どおり有効です。ある層の出力と、層に入ってきた入力を単純に足し合わせる構成を入れると、入力が後の層まで直接伝わる経路ができます。この経路があることで、もし新しい層がまだ適切な変換を学んでいなくても、最初から入力を失わずに動かせます。

直感B — 「値の平均とばらつきを揃えておくと、次の層が安定して学べる」
多くの学習アルゴリズムは入力のスケールや平均に敏感です。学習中に各層の出力分布が変わると、次の層が入力分布の変化に対応するために余分な調整を必要とします。各位置（単語など）について、その位置の特徴ベクトル全体の平均やばらつきを整える処理を入れると、下流が受け取る信号のスケールが安定します。

しかし重要な注意点：
- 「足すだけで全て解決する」わけではありません。足し戻す経路は情報を守る手助けをしますが、適切な重みの学習や学習率の選定など他の要素も必要です。
- 「平均と分散を揃えれば解決する」わけでもありません。正規化は安定させますが、正規化の詳しい定義（どの軸で統計を取るか、平均を引くかどうか、スケールパラメータを学習するか）で効果は変わります。
- 層ごとの処理は確率的・データ依存なので、直感をそのまま数学的に置き換えた場合と異なる挙動をすることがあります。

数値オブジェクト、学習パラメータ、活性化（activation）の区別を明確にする

説明で使う要素は3種類に分けて扱います。

1. 入力や中間の「活性化」(activations)：ネットワークに流れる数値ベクトル。例：x = [2, -1]。学習中はバッチごとに変わる実データ由来の数値です。
2. サブレイヤの出力（活性化の一種）: ある処理ブロックを通した後に得られるベクトル。例：F(x) = [0.5, 1]。
3. 学習可能パラメータ（parameters）：スケール係数やバイアスなど、学習で更新される定数。例：gamma, beta。学習プロセスによって値が変化します。

この区別を守ることで、どの数がデータに依存しどの数が学習されるかを混同せずに説明できます。

まずは具体例 — 足し戻し（残差経路）の計算と短いLayerNormの教育的計算

与える入力（活性化）： x = [2, -1]
あるサブレイヤが出す出力（活性化）： F(x) = [0.5, 1]

まず足し戻す（加える）操作を行います。これは技術的には「入力を保持する経路」と「新しい変換の経路」を単純に足すものです。

計算:
x + F(x) = [2 + 0.5, -1 + 1] = [2.5, 0]

この [2.5, 0] がその層の次のステップへ渡される活性化です。重要：x と F(x) はどちらも活性化であり、ここで足し合わせても学習パラメータは増えません（ただしサブレイヤの内部には学習される重みがある）。

次に、教育用に別のベクトル [2, 4] の平均と分散を使って Layer Normalization の計算を示します。ここでは学習パラメータ gamma（スケール）と beta（シフト）を単純に gamma=1, beta=0 と仮定します。実際のモデルでは gamma, beta は学習されるパラメータです。

与えられたベクトル: v = [2, 4]
平均 μ = (2 + 4) / 2 = 3
分散 σ^2 = ((2-3)^2 + (4-3)^2) / 2 = (1 + 1) / 2 = 1
標準偏差 σ = sqrt(1) = 1

LayerNorm の正規化（epsilon を 1e-5 とする）:
v_normalized = (v - μ) / sqrt(σ^2 + ε) = ([2-3, 4-3]) / sqrt(1 + 1e-5) ≈ [-1, 1] （ほぼそのまま）

その後にスケールとシフトを適用すると、出力 = gamma * v_normalized + beta。gamma=1, beta=0 の場合は [-1, 1] 。

ここで明確にする点：上の [2,4] に対する平均・分散の計算は「教育目的の例」で、モデル内部で使われる統計は通常そのサンプルの活性化（例：[2.5, 0]）について計算されます。今回は計算手順を見せるために簡単な別ベクトルを用いました。実モデルの数値はこれらの例よりはるかに多次元かつ異なる大きさの値を取ります（教育用の小さな整数は本質的に概念説明用であり、実モデル内部の典型値ではありません）。

式でのまとめ（記号の意味を普通の言葉で）

残差（足し戻し）の基本式（1サンプル・1位置のベクトルで考える）：
y = x + F(x)

- x : サブレイヤに入る元の活性化ベクトル（例: 埋め込みや前層の出力）
- F(x) : そのサブレイヤ（注意機構や位置ごとのフィードフォワードなど）を通した出力ベクトル
- y : 足し戻しの後の活性化（次の処理へ渡される）

Layer Normalization の基本式（1サンプル・1位置、d 次元のベクトル x を正規化する例）：
μ(x) = (1/d) * sum_{i=1..d} x_i
σ^2(x) = (1/d) * sum_{i=1..d} (x_i - μ(x))^2
LN(x) = γ ⊙ (x - μ(x)) / sqrt(σ^2(x) + ε) + β

- μ(x) : ベクトル x の成分全体の平均（その「位置」の特徴平均）
- σ^2(x) : 平均からの二乗偏差の平均（分散）
- ε : 数値安定化のための小さい正数（例 1e-5）
- γ（ガンマ）: 学習されるスケール係数（d成分あることが多い） — 学習パラメータ
- β（ベータ）: 学習されるシフト（オフセット） — 学習パラメータ
- ⊙ : 各成分ごとの掛け算（成分毎のスケーリング）

RMSNorm（平均を引かない変種）の式（平均を用いず、二乗平均のみを用いる）：
rms(x) = sqrt( (1/d) * sum_{i=1..d} x_i^2 )
RMSN(x) = γ ⊙ (x / (rms(x) + ε))

- RMSNorm は中心化（平均を引く）をしないため、平均0にする操作を省きたい場面で使われます。γ は学習パラメータです。

実例をもとにした完全な計算（先の数値を再掲し、役割を明示）

例の再掲：
- 活性化（入力） x = [2, -1]  （活性化、データ依存）
- サブレイヤ出力 F(x) = [0.5, 1]  （活性化、データ依存）
- 足し合わせ結果 y = [2.5, 0]  （活性化）

教育用 LayerNorm（別ベクトル v = [2, 4] を用いた例）：
- v = [2, 4]
- μ = 3, σ^2 = 1, sqrt(σ^2 + ε) ≈ 1.000005
- 正規化 v̂ = (v - μ) / sqrt(σ^2 + ε) ≈ [-0.999995, 0.999995] ≈ [-1, 1]
- 出力 = γ * v̂ + β（γ=1, β=0 の場合は [-1, 1]）

ここでは x、F(x)、y、v はすべて活性化で、γ、β は学習パラメータです。実モデルでは γ と β は通常 d 次元のベクトルで、各成分を別々にスケーリング・シフトします。

透明な短いPythonコード（数式と対応する変数名）

次のコードは NumPy を使った教育用の実装例です。変数名は上の式と対応しています。transform(x) のような抽象呼び出しは使わず、ベクトル演算をそのまま書いています。

```python
import numpy as np

eps = 1e-5

x = np.array([2.0, -1.0])        # 入力活性化
Fx = np.array([0.5, 1.0])        # サブレイヤ出力

# 残差（足し戻し）
y = x + Fx                        # y = x + F(x)
print("residual y =", y)         # [2.5, 0.0]

# 教育用 LayerNorm を別ベクトル v=[2,4] で計算
v = np.array([2.0, 4.0])
mu = v.mean()                     # 平均
var = ((v - mu) ** 2).mean()      # 分散
std = np.sqrt(var + eps)
v_norm = (v - mu) / std
gamma = np.array([1.0, 1.0])      # 学習パラメータ（例）
beta = np.array([0.0, 0.0])       # 学習パラメータ（例）
v_out = gamma * v_norm + beta
print("LayerNorm of [2,4] ->", v_out)  # 約 [-1, 1]

# RMSNorm の例（v を用いる）
rms = np.sqrt((v ** 2).mean() + eps)
gamma_rms = np.array([1.0, 1.0])
v_rms_out = gamma_rms * (v / rms)
print("RMSNorm of [2,4] ->", v_rms_out)
```

このコードは教育目的です。実モデルでは d（次元）が数百から数千、バッチやシーケンスの処理、分散トレーニング、数値安定化の工夫（例えばより大きな ε や混合精度対応）などが加わります。

元の Transformer と近年の採用例の違い（混同に注意）

- Vaswani et al. (2017) のオリジナルTransformerでは、各サブレイヤ（自己注意やフィードフォワード）の出力を入力に足し、その結果に LayerNorm を適用する、いわゆる「Add & Norm」が用いられました。式で書くと：
  x_{l+1} = LayerNorm( x_l + Sublayer(x_l) )
  これをポスト正規化（post-LN）と呼びます。

- その後の研究と実装では「正規化をサブレイヤに入る前に置く」方式（pre-LN）が多く使われています。pre-LN の典型的な式：
  x_{l+1} = x_l + Sublayer( LayerNorm(x_l) )
  pre-LN の利点は、深いモデルで学習がより安定しやすく、勾配の流れが改善されることです。特に非常に深い層を持つモデルや学習率の大きな設定では安定化が重要になります。

- GPT 系（Decoder-only）やその亜種の実装では、pre-LN が採用される場合が増えていますが、これは実装やトレーニング手順による選択で、すべてのモデルが同じではありません。つまり「GPTは常にpre-LN」という一般化は避けてください。実際の採用状況は論文や公開実装ごとに異なります。

- LayerNorm と RMSNorm について：LayerNorm は平均中心化（mean subtraction）と分散で割る操作を行い、γ, β の両方を持ちます。RMSNorm は平均を引かず、二乗平均の平方根で割るだけにしてパラメータを減らす手法です（γ のみを学習することが多い）。RMSNorm は計算コストや数値安定性の面で有利なことがあるため、近年の実装で採用されることがあります。ただし、RMSNorm が必ず良いというわけではなく、用途・構造・学習手法によって選択は変わります。modern variations を扱うときは、採用が広く一般化されていると書かないこと。

Full Transformer 内での前後の処理と実際の接続点

典型的なTransformer層の流れ（サブレイヤは自己注意とフィードフォワードの2種類）を簡潔に書くと：

1. 入力（位置ごとの d 次元ベクトル群、埋め込み＋位置情報）
2. 層 l の自己注意サブレイヤ：注意計算 → 出力（活性化）
3. 残差足し戻し：入力を足す（x + Attention(x)）
4. 正規化（post-LNの場合）または正規化してから注意に入れる（pre-LNの場合）
5. 層内の位置ごとのフィードフォワードサブレイヤ：位置ごとに独立に適用
6. 再び残差足し戻しと正規化

重要な実務的注意点：
- 残差経路は「情報をそのまま伝える」という意味合いがありますが、実際には次のサブレイヤの出力が加算されることで、その層が「差分」を学ぶように働くという解釈は有用です。「層は単に差分だけ学べば良い」は過度な単純化です。学習の過程や目的によって最適な変換は異なります。
- 正規化（LayerNorm 等）は、モデル全体の学習安定性に寄与しますが、どの場所に置くか（pre / post）やどの正規化を使うか（LayerNorm / RMSNorm / 他）でトレーニングダイナミクスや性能が変わります。設計は経験に依存する部分が大きいです。
- 実用の実装では、残差のスケーリング（例えば 1/sqrt(2) を掛ける、あるいは学習可能なスケーリング係数を入れる）や、残差に対するドロップアウトを施すことがよくあります。これらは正則化や数値安定化のための工夫です。

よくある誤解の訂正（少なくとも一つ）

誤解：「注意（attention）の重みは人間が『どこを注目したか』の完全な説明である」
訂正：注意重みはモデル内部の計算で得られる係数であり、人間の直感的な「注目」と対応することもあれば、そうでないこともあります。注意重みは最終的な出力を形成するための数式的な重みであり、その分布を見れば何が行われているかの手がかりを与えることはありますが、それだけでモデルの判断理由を完全に説明するものではありません。

誤解：「残差を足すから層は何もしなくて良い」
訂正：残差経路があると、ある意味で層は「恒等写像をデフォルトで持てる」ことになりますが、学習過程でサブレイヤは依然として重要な変換を学びます。残差は学習のハードルを下げる補助であって、無条件に層を不要にするわけではありません。

小さな実務的注記（実モデルでの現実）
- 教育用の小さな整数（例: 2, -1, 0.5）は説明を分かりやすくするためのもので、実際の大規模言語モデルの内部活性化は次元が非常に大きく、値域も異なります。これらは概念を伝えるためのモデル化された数値です。
- 「トークン」は単語と同義ではありません。実際の実装ではトークンはサブワードやバイトペアなどの単位で、語より細かい場合があります。
- BatchNorm のようなバッチ単位の正規化は、可変長なシーケンスや小さなバッチを扱う言語モデルでは扱いにくいため、通常 LayerNorm や RMSNorm のようなサンプル単位の正規化が好まれます。
