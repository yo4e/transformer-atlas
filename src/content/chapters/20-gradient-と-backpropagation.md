# Gradient と backpropagation

1. 問題の提示――なぜ「どちらへ動かすか」を知る必要があるのか
あなたが何かを最適化したいとします。例えば機械翻訳モデルが「よりよい訳」を出すように調整したいとき、ある多数の内部数値（これをパラメータと呼びます）を少しずつ変えます。重要なのは「今持っているパラメータを少し動かすと、評価値（損失）が上がるか下がるか」がわかることです。もし下がる方向がわかれば、その方向へ少しずつ動かして損失を減らせます。逆に、どちらへ動かせばよいかわからなければランダムに探索するしかなく、膨大な試行が必要になります。

この章はその「局所的な感度」を数値的に求める仕組み（後で名前を出します）を、大学での微積分を前提にしないやり方で説明します。必要な考えは「微小な変化に対する線形近似」と「合成関数の積み重ねを数値で伝える方法」です。先に結論めいた名前は伏せ、まず直感と具体的な計算で示します。

2. まずは直感――傾きと一番単純な更新
一次元の単純な例で直感を作ります。関数
L(θ) = (θ − 3)^2
を考えます。θは調整するパラメータ、Lはそのときの損失（数字が小さいほど良い）です。θの周りでの「傾き」を見ると、右へ少し進んだときに損失が増えるか減るかがわかります。数学的に言えば、θ=1での傾きは
L'(θ) = 2(θ − 3) ⇒ L'(1) = 2(1 − 3) = −4
です。傾きが −4 というのは、小さな増分 Δθ を右（大きい方向）に動かすと損失はおよそ −4 × Δθ だけ変わる、という意味です。負の傾きなら右へ進むと損失が減る、という単純な結果が得られます。

実際の更新は「どのくらい右へ動かすか」を決める学習率（learning rate, ここでは 0.1 ）を使って行います。一般的な単純更新は
θ ← θ − η · L'(θ)
です（η は学習率）。この式は「損失を減らすために、傾きの符号と逆方向へ少し動く」という意味です。数を代入すると
θ ← 1 − 0.1 × (−4) = 1 + 0.4 = 1.4
となり、θ は 1.4 に更新されます。これが本章で必ず通す具体例です。以降、この単純な算数的計算を足場に、複数のパラメータや深い合成関数へ拡げていきます。

注意点（直感がそのまま成り立たない場面）
- 傾きが局所情報であること：傾きはその点の「局所的」な変化を示すだけで、遠くへ大きく動いたときの挙動は保証しません。
- 傾きが小さい（平ら）でもその先に重要な下がり道があることがあります。逆に、傾きが大きいからといって必ずグローバルに良い方向とは限りません。
- 実際の学習では勾配のスケール（大きさ）やノイズ、複数のパラメータ間の相互作用が重要です。ここでは局所感度の数値的理解を優先します。

3. パラメータ・入力・活性化の区別――言葉をそろえる
混乱を避けるために用語をはっきりさせます。
- パラメータ（parameters）：調整する数値。例：θ、行列 W、バイアス b。
- 入力（inputs）：モデルに与える観測や埋め込み。例：x（ベクトル）、トークンの埋め込みベクトル。
- 活性化（activations）：入力とパラメータから計算される中間出力。例：z = W x + b や a = σ(z)。活性化は入力の変換結果で、学習ではこれらを通じて損失に影響します。

4. 合成関数と「連鎖」の数値的説明
実際のモデルは処理を何段も合成します。簡単な合成を例に取ると、
θ → v = θ + 1 → u = v^2 → L = (u − 3)^2
という流れがあったとします。θが損失にどれだけ影響するかは、各段の局所的な変化を掛け合わせて求めます。数で示すと分かりやすいです。θ=1 のとき各値は
v = 2, u = 4, L = (4−3)^2 = 1
局所微分（傾き）を順に計算します（ここでは小学校の掛け算・引き算レベルの数）：
- ∂v/∂θ = 1（v = θ + 1 なので変化は等しい）
- ∂u/∂v = 2v = 4（u = v^2）
- ∂L/∂u = 2(u − 3) = 2(1) = 2
連鎖的に考えると、θ が L に与える影響はこれらの積です：
∂L/∂θ = (∂L/∂u)·(∂u/∂v)·(∂v/∂θ) = 2 · 4 · 1 = 8
つまり、θ を右へ 0.01 動かすと L はおよそ 0.08 増える（局所線形近似）という意味です。これが「連鎖（chain）」の数値的な直観です。

5. 多変数（行列・ベクトル）の例――小さなニューラルの一段
次に、実際にニューラルネット風の簡単な例を示します。ここでも算数で計算できる小さな値を使います。モデルは1層の線形変換の後に二乗誤差（mean squared error）を使います。定義：
- パラメータ：重みベクトル w ∈ R^2（成分 w1, w2）、バイアス b（スカラー）。
- 入力：x ∈ R^2（成分 x1, x2）。
- 出力（予測）：ŷ = w·x + b = w1 x1 + w2 x2 + b（スカラー）
- 目標（ターゲット）：t（スカラー）
- 損失：L = (ŷ − t)^2（スカラー）

ここで「·」は内積で、「行列積」や「軸」は普通の掛け算の集合です。w は列ベクトル、x は列ベクトルなら ŷ = w^T x + b と書けますが、見た目よりも「各要素を掛けて足し合わせる」ことを意識してください。

具体的な数でやります。設定：
w = [0.5, −1.0], b = 0.0
x = [2.0, 1.0], t = 1.0
まず順伝播（forward pass）：
ŷ = 0.5×2.0 + (−1.0)×1.0 + 0.0 = 1.0 − 1.0 = 0.0
損失：
L = (0.0 − 1.0)^2 = 1.0
次にパラメータごとの偏微分（局所傾き）を数値で求めます。チェインルールを成分ごとに使います：
∂L/∂ŷ = 2(ŷ − t) = 2(0.0 − 1.0) = −2.0
∂ŷ/∂w1 = x1 = 2.0 なので ∂L/∂w1 = ∂L/∂ŷ × ∂ŷ/∂w1 = −2.0 × 2.0 = −4.0
∂ŷ/∂w2 = x2 = 1.0 なので ∂L/∂w2 = −2.0 × 1.0 = −2.0
∂ŷ/∂b = 1 なので ∂L/∂b = −2.0 × 1 = −2.0
これらは「各パラメータを少しだけ増やすと損失がどう変わるか」を示す数です。負の値は「そのパラメータを増やすと損失が減る」ことを意味します。たとえば w1 は −4 なので、増やす方向に動かすと損失が下がる（右へ動かすのが良い）ことを示しています。

更新（学習率 η = 0.1 とする）：
w1 ← 0.5 − 0.1 × (−4.0) = 0.5 + 0.4 = 0.9
w2 ← −1.0 − 0.1 × (−2.0) = −1.0 + 0.2 = −0.8
b ← 0.0 − 0.1 × (−2.0) = 0.2

これで一回の「勾配に基づく更新」を行ったことになります。重要なのは、ここでの計算は単純な掛け算と引き算で表せるという点です。行列積やベクトルの形は「多数のそうした掛け算をまとめて書いたもの」に過ぎません。各要素の寄与を順に計算していくのが実際のアルゴリズムです。

6. 実際のアルゴリズム（backpropagation）の役割
上の手計算を大きなネットワークで効率よくやるのが backpropagation（逆伝播）です。ポイントは二つ。
- 各中間ノード（活性化）の値を順伝播で計算・保存する。
- 逆方向に、それぞれの局所微分を掛け合わせていくことで、最終的に各パラメータの勾配を得る。

なぜ保存するかというと、合成関数に対して同じ中間値が勾配の複数箇所で使われるからです。再計算すると時間がかかるため、一度の順伝播で値を保存し、逆方向で使います。要するに「計算グラフをたどって、各局所の勾配を掛けていく」操作が backpropagation です。

7. 数値で確認する短い Python（numpy）コード
以下のコードは上の単純な1層例をそのまま実行して、解析的な勾配と有限差分（数値微分）で一致することを確認します。変数名は本文の記法に合わせています。

```python
import numpy as np

w = np.array([0.5, -1.0])   # w1, w2
b = 0.0
x = np.array([2.0, 1.0])
t = 1.0
eta = 0.1  # 学習率

# 順伝播
y_hat = w.dot(x) + b
L = (y_hat - t)**2

# 解析的勾配（チェインルール）
dL_dy = 2.0 * (y_hat - t)
dL_dw = dL_dy * x       # 要素ごとに掛け算
dL_db = dL_dy * 1.0

# 有限差分で確認（小さな増分で数値微分）
eps = 1e-6
num_grad_w = np.zeros_like(w)
for i in range(len(w)):
    w_eps = w.copy()
    w_eps[i] += eps
    y_hat_eps = w_eps.dot(x) + b
    L_eps = (y_hat_eps - t)**2
    num_grad_w[i] = (L_eps - L) / eps

# 出力
print("y_hat, L:", y_hat, L)
print("analytic grad w:", dL_dw, "analytic grad b:", dL_db)
print("numeric grad w:", num_grad_w)

# 更新
w_new = w - eta * dL_dw
b_new = b - eta * dL_db
print("updated w:", w_new, "updated b:", b_new)
```

このコードでは `dL_dw` の各成分が手計算と一致し、有限差分でもほぼ同じ値が得られるはずです。実際の学習フレームワーク（PyTorch, TensorFlow 等）はこの手順を自動化しますが、内部でやっていることは同じです。

注：ここで示した数値（例えば w の値や学習率など）は教育目的のものです。実際の大規模モデル内部の値や学習率の最適値は全く別の次元で、ここでの小さな数は実モデルの内部状態を直接表すものではありません。

8. Transformer の中での前後の処理と backpropagation の流れ
Transformer（原論文の「Attention Is All You Need」を基にした構成）では、入力トークンはまずトークナイズされ、各トークンは埋め込み（embedding）というパラメータ行列によってベクトルに変換されます。位置情報は別の埋め込みや位置エンコーディングで加わります。そこから複数のレイヤ（自己注意層とフィードフォワード層の繰り返し）を通り、最終的に出力は「ロジット」と呼ばれる数値列に変換され、softmax とクロスエントロピー損失で評価されます。

損失が与えられると、backpropagation は最終出力から逆方向に流れ、まず softmax とクロスエントロピーの局所勾配を計算し、それを出力層のパラメータ（例えば出力の線形変換の重み）に伝えます。さらに自己注意のスコア計算、キー・クエリ・バリューの線形変換、LayerNorm、残差接続などを順にさかのぼって勾配を伝播させ、最終的に埋め込みや全ての重みへ勾配が集まります。

注意点：
- softmax の微分は非直交な構造を持つため、出力間での依存を生みます（ある出力を変えると他の出力の確率も変わる）。
- attention weight を「どれだけ注目したかの証拠」と単純に読み取るのは誤解です。attention weight は計算途中の線形変換の結果から導かれる確率分配に過ぎず、人間的な「意味的重み付け」の完全な証拠にはなりません。

9. よくある誤解の訂正
- 「勾配が0なら完璧」ではない：勾配がゼロの点には極小・極大・鞍点（saddle point）などがあり得ます。勾配のみで最終的な良さを判断するのは不十分です。
- 「attention weight は説明可能性の証拠」ではない：attention weight はモデルの計算経路の一部であり、単純に「ここを参照している」と人間の直感で結びつけるのは危険です。
- 「数値が小さければ安全」ではない：学習率や勾配のスケールは相互に影響します。微小な勾配が累積すると大きな変化を生むこともあります。

10. 大規模モデルとの接続と制約
実際の Transformer 系モデルは数千万から数百億のパラメータを持ちます。backpropagation は同じ原理で動きますが、スケール・並列化・数値安定性（勾配消失や発散）に注意が必要です。またトークンは単語と同義ではなく、サブワード単位やバイトペア符号化（BPE）などが使われていることが普通です。したがって「ある単語の埋め込みが変わったから翻訳が変わった」と単純に結びつけるのは難しい面があります。さらに、提示した小さな数値例は教育目的のものであり、実モデルの内部状態をそのまま示すものではありません。

11. 締めと学習の確認
この章では、パラメータを少し動かしたときに損失がどちらへ変わるか（局所感度）を算数ベースで求める方法を示しました。チェインルールは合成関数の局所微分を掛け合わせることで成り立ち、backpropagation はこれを効率的に実行する手続きです。多変数の場合でも各成分は局所的な寄与を積み上げて求められます。
