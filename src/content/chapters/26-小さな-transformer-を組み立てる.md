# 小さな Transformer を組み立てる

はじめに — まず解くべき問題を提示する
機械翻訳や文章生成で使われる「自己注意」による情報の混ぜ方を、小さな実行可能例で完全に追えるようにします。具体的には「短い語列（トークン列）を受け取り、各位置でどの過去の位置の情報をどれだけ使って出力を作るか」を、実際の数値で順を追って計算します。なぜこれが必要かというと、Transformer の処理は多数の行列積といくつかの非線形変換の組合せであり、理屈だけでなく数値の流れ（どの配列が学習可能なパラメータで、どれがその時点での活性化か）を手で追えることが理解の近道だからです。

注意：本章で使う小さい小数値・行列は教材用の単純化された例であり、実際の大規模モデルの内部で使われる値や分布を反映するものではありません。また「トークン」は厳密には単語ではなく、サブワードなどの単位になり得ます。Attention の重みをそのまま人間の「注目」の証拠とみなすのも誤解を生みやすい（後半で訂正します）。

概要と直感（文字どおりではない点も明示）
処理の直感はこうです。各位置の入力ベクトル（埋め込み）から「問い（Query）」「候補（Key）」「中身（Value）」の三つのベクトルを線形に作り、問いと候補の類似度で重みを決めて、中身を重み付き平均します。重みの計算にはスケール（ベクトル次元の平方根）とソフトマックスを入れて数値安定化します。直感として「重みが大きければその位置を参照している」と言えますが、注意点は：重みは学習された行列や入力ベクトルに強く依存し、必ずしも人間の意味的な「注目」に直結しない、ということです。

扱うものの分類（重要）
- 学習可能なパラメータ（weights, biases）── 実装では行列 W_Q, W_K, W_V, W_O, W_1, W_2 など。
- 入力（固定されたトークンID列、またはミニバッチ）── 本章の具体例では token_ids = [2, 4, 3]。
- 活性化（forward pass 中に計算される中間配列）── 埋め込み、Q/K/V、スコア、確率、最終出力など。

26.1 使う小さな具体例（この後ずっと用いる実値）
以下は examples/tiny_transformer.py にある例と同じ値を使うと仮定した、完全に具体的な初期設定です（繰り返しますが教育用途の簡易数値です）。

- vocab_size = 6
- d_model = 4
- token_ids = [2, 4, 3] （系列長 = 3）
- 単純化した埋め込み行列 E（shape 6×4、行は token id に対応）:
  e0 = [0.1, 0.0, 0.0, 0.0]
  e1 = [0.0, 0.2, 0.0, 0.0]
  e2 = [0.0, 0.0, 0.3, 0.0]
  e3 = [0.0, 0.0, 0.0, 0.4]
  e4 = [0.1, 0.1, 0.1, 0.1]
  e5 = [0.2, 0.0, 0.1, 0.0]

これにより入力埋め込み行列 X（3×4）は、
x0 = e2 = [0, 0, 0.3, 0]
x1 = e4 = [0.1, 0.1, 0.1, 0.1]
x2 = e3 = [0, 0, 0, 0.4]

ネットワークの簡単化された学習パラメータ（教材用、分かりやすさ優先）
- W_Q = I (4×4 単位行列)、W_K = I、W_V = I（つまり Q = X, K = X, V = X）
- 出力投影 W_O = I（ここでは混合層を恒等写像で扱う）
- FFN（MLP）は 2 層で、W_1 = 2·I、活性化は ReLU、W_2 = I、バイアスは 0

26.2 数式での記述と「普通の言葉」への戻し
まず数式で書くと（1ヘッド、バッチ無視、系列長 = T、とする）:

- 埋め込み: X ∈ R^{T×d}
- Query, Key, Value:
  Q = X W_Q
  K = X W_K
  V = X W_V
  （ここで W_Q,W_K,W_V ∈ R^{d×d} は学習可能な行列）
- スコア（生スコア）: S = Q K^T / sqrt(d_k)
  （d_k は Q,K の次元、ここでは d）
- マスクの加算: S' = S + M  （M は許可されない要素に大きな負値を入れる行列）
- 確率（行ごとの softmax）: P = softmax(S' rowwise)
- Attention 出力（混合）: O = P V
- 出力投影（必要なら）: Y = O W_O
- 残差結合と FFN: Z = Y + X  （前段の残差）
  FFN_out = W_2( ReLU( Z W_1 ) )
  Final = Z + FFN_out

普通の言葉に戻すと：
- 埋め込み X は各位置に対応する数ベクトルの一覧です。
- Q は「いま調べたい特徴」、K は「候補の特徴」、V は「候補が持っている実際の情報」です。
- Q と K の内積は「Q が K とどれだけ合うか」。そのままだと値の幅が大きくなるので d_k の平方根で割ります。
- マスクは将来トークンを参照しない（自己回帰）ために未許可のペアを非常に小さく（負無限）します。
- softmax はその行のスコアを非負の重み（合計 1）に変えて、重み付き平均を意味的に解釈できるようにします。

26.3 手計算で追う：Q, K, V, スコアから確率、出力まで（すべての数値）
Q = X, K = X, V = X なので Q,K,V は次の 3×4 行列です（行は時刻 0,1,2 に対応）:
q0 = [0, 0, 0.3, 0]
q1 = [0.1,0.1,0.1,0.1]
q2 = [0, 0, 0, 0.4]

QK^T を成分ごとに計算すると（i 行 j 列 = q_i · k_j）:
[[0.09, 0.03, 0.0],
 [0.03, 0.04, 0.04],
 [0.0, 0.04, 0.16]]

スケーリング因子は sqrt(d_k) = sqrt(4) = 2 なので生スコア S = QK^T / 2 は
S =
[[0.045, 0.015, 0.0],
 [0.015, 0.02,  0.02],
 [0.0,   0.02,  0.08]]

因果マスク M（未来の参照を禁止するため）を加える。ここでは未許可要素に -1e9 を足すやり方を使うので、
S' =
[[0.045, -1e9,  -1e9],
 [0.015, 0.02,  -1e9],
 [0.0,   0.02,   0.08]]

行ごとに softmax を取ると、
- 行 0: softmax([0.045, -1e9, -1e9]) ≈ [1.0, 0.0, 0.0]
- 行 1: softmax([0.015, 0.02, -1e9]) -> 比は exp(0.015):exp(0.02) = 1.01511 : 1.02020 -> 正規化して [≈0.498, ≈0.502, 0]
- 行 2: softmax([0, 0.02, 0.08]) -> exp = [1.0, 1.02020, 1.08329], 合計 ≈ 3.10349 -> [≈0.3222, ≈0.3288, ≈0.3490]

これを P とする。Attention 出力 O = P V を各行で計算すると（列は埋め込み次元）:
- out0 = 1·v0 + 0·v1 + 0·v2 = v0 = [0, 0, 0.3, 0]
- out1 = 0.498·v0 + 0.502·v1 = [0.0502, 0.0502, 0.1996, 0.0502]（計算を示した）
- out2 = 0.3222·v0 + 0.3288·v1 + 0.3490·v2 = [0.03288, 0.03288, 0.12954, 0.17248]

出力投影 W_O = I のため Y = O.

残差結合: Z = Y + X（位置ごとに加算）
- z0 = [0, 0, 0.6, 0]
- z1 = [0.1502, 0.1502, 0.2996, 0.1502]
- z2 = [0.03288,0.03288,0.12954,0.57248]

FFN（ここでは W_1 = 2I, ReLU, W_2 = I）を適用し、最終出力 = Z + FFN_out:
- ffn_in0 = 2·z0 = [0, 0, 1.2, 0] -> ReLU はそのまま
  Final0 = z0 + ffn0 = [0, 0, 1.8, 0]
- ffn_in1 = 2·z1 = [0.3004,0.3004,0.5992,0.3004]
  Final1 ≈ [0.4506,0.4506,0.8990,0.4506]
- ffn_in2 = 2·z2 = [0.06576,0.06576,0.25908,1.14496]
  Final2 ≈ [0.09864,0.09864,0.38862,1.71744]

出力から語彙ごとのスコア（ロジット）を作るには、簡便のため埋め込み行列の転置をワード分布のスコアに使う（weight tying）。つまり各語 i に対して logit_i = final · e_i。
計算例（位置 0 のロジット）:
- logit_2 = final0 · e2 = [0,0,1.8,0] · [0,0,0.3,0] = 1.8·0.3 = 0.54
同様に位置 1,2 のロジットも上で示したとおり（数値列を本文末に短くまとめます）。

26.4 各関数（embedding, QKV, score, mask, softmax, mixing, residual, MLP, logits）の入出力表（章番号つき）
表は「章番号 — 関数名 — 入力（実例） — 出力（実例）」の形式です。章番号は本章内の小節番号です。

26.4.1 — embedding
- 入力: token_ids = [2,4,3]
- 出力: X = [[0,0,0.3,0],[0.1,0.1,0.1,0.1],[0,0,0,0.4]]

26.4.2 — QKV
- 入力: X, W_Q=W_K=W_V=I
- 出力: Q=K=V = X（上と同じ）

26.4.3 — score
- 入力: Q,K
- 出力: S = QK^T / 2 = [[0.045,0.015,0],[0.015,0.02,0.02],[0,0.02,0.08]]

26.4.4 — mask
- 入力: S, causal mask M
- 出力: S' = S + M = 上で示した -1e9 を含む行列

26.4.5 — softmax
- 入力: 各行の S'
- 出力: P（行0: [1,0,0], 行1: [≈0.498,≈0.502,0], 行2: [≈0.3222,≈0.3288,≈0.3490]）

26.4.6 — mixing（attention 出力）
- 入力: P, V
- 出力: O（out0=[0,0,0.3,0], out1=[0.0502,0.0502,0.1996,0.0502], out2=[0.03288,0.03288,0.12954,0.17248]）

26.4.7 — residual
- 入力: O, X
- 出力: Z = X + O（数値は本文にある）

26.4.8 — MLP (FFN)
- 入力: Z, W_1=2I, W_2=I
- 出力: FFN_out および Final = Z + FFN_out（数値は本文にある）

26.4.9 — logits
- 入力: Final, E^T（埋め込み転置）
- 出力: 各位置の語彙ロジット（位置 0 の例: [0,0,0.54,0,0.18,0.18]）

26.5 実装例（透明で短い Python）
以下は上の計算を忠実に再現するスクリプト抜粋です。変数名は数式と対応しています。

```python
import math
import numpy as np

E = np.array([
 [0.1,0.0,0.0,0.0],  # e0
 [0.0,0.2,0.0,0.0],  # e1
 [0.0,0.0,0.3,0.0],  # e2
 [0.0,0.0,0.0,0.4],  # e3
 [0.1,0.1,0.1,0.1],  # e4
 [0.2,0.0,0.1,0.0],  # e5
])
token_ids = [2,4,3]
X = E[token_ids]           # (T=3, d=4)

W_Q = np.eye(4); W_K = np.eye(4); W_V = np.eye(4)
Q = X.dot(W_Q)
K = X.dot(W_K)
V = X.dot(W_V)

# スコア
d_k = Q.shape[1]
S = Q.dot(K.T) / math.sqrt(d_k)  # (3,3)

# 因果マスクを加算する（未許可 = -1e9）
M = np.triu(np.full(S.shape, -1e9), k=1)  # 未来を封じる上三角を -1e9
S_masked = S + M

# softmax（行ごと）
def row_softmax(mat):
    out = np.zeros_like(mat)
    for i in range(mat.shape[0]):
        row = mat[i]
        # 数値安定化
        row = row - np.max(row)
        ex = np.exp(row)
        out[i] = ex / np.sum(ex)
    return out

P = row_softmax(S_masked)

# attention 出力
O = P.dot(V)

# 残差
Z = O + X

# FFN の適用（W1=2I, ReLU, W2=I）
FFN_in = 2.0 * Z
FFN_out = np.maximum(FFN_in, 0.0)
Final = Z + FFN_out

# logits（埋め込み転置を使う）
Logits = Final.dot(E.T)
print("Logits per position:\n", np.round(Logits, 6))
```

このスクリプトを実行すれば、上で手計算した数値と一致するはずです（丸め誤差レベルの差を除く）。

26.6 全体の前後関係と現実の大きなモデルとの接続
- 前段: 実際のモデルではトークン化（BPE 等）→ token ids → 埋め込み → 位置エンコーディング（加算または相対位置表現）があります。本例では位置エンベディングを省略しましたが、実用では通常入れます。
- 本段: 本章は「デコーダー1層（自己注意 + FFN）」を示しました。大きなモデルではこれが多数スタックされ、各層で LayerNorm、ドロップアウト、多頭注意（複数ヘッド）などが入ります。
- 後段: 最終ロジットに対し softmax を取ると語彙分布が得られ、教師あり学習では交差エントロピー損失を計算してパラメータを更新します。生成ではその分布から次のトークンをサンプリングまたは確率最大のものを選び、次ステップの入力にフィードバックします。

26.7 よくある誤解の訂正（少なくとも一つ）
誤解: 「Attention の重みは、モデルがどの単語に '注目' しているかを人間的にそのまま示す証拠だ」
訂正: Attention 重みは確かにモデルの内部処理を示すヒントになりますが、重みは行列の線形変換と非線形活性化を介して出力に影響し、その間に残差や正規化、次の層の重みが介在します。ある重みが大きいからといって、それが意味的に明瞭な「理由」を与えるとは限りません。解釈は慎重に行う必要があります。

26.8 練習問題（確認問題）と学習のチェックリスト
読了後に説明できること（チェックリスト）
- 埋め込み（token id → ベクトル）と、その行列が学習パラメータか入力変数かを区別できる。
- Query/Key/Value の役割と、内積→スコア→softmax→重み付き平均の数値経路を説明できる。
- マスクがどのように softmax 前に適用されるか、数値的に何をしているかを述べられる。
- 残差接続と FFN の簡単な目的（安定化・表現の拡張）を説明できる。
- 教材用数値と実際の大規模モデル内部の値が異なる理由を述べられる。

確認問題（解答は別に用意）
1) 上の具体例で、もし W_Q を 2·I に変えると、行 2（最後の位置）の softmax 確率はどのように変わりますか？（概念的に：Q が大きくなればスコアの振れ幅が増える → softmax がより尖る。具体的な数値変化を計算してみてください。）
2) 位置 1 の最終ロジット列（位置 1 の Logits）を用いて、その位置で最も確率が高くなる語彙がどれかを求め、なぜその語が高いスコアになっているかを数値的に説明してください。（Hint: 最終ベクトルと語彙埋め込みの内積がロジットです。）
