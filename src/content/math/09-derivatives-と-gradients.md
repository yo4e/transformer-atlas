# Derivatives と gradients

はじめに。Transformer の学習では「損失（loss）」を小さくするためにモデルのパラメータを更新します。その更新の基礎になるのが勾配（gradient）です。本稿は大学数学を前提にせず、勾配が「パラメータの微小変化に対する損失の局所的な感度」であることを直感的に説明し、なぜ Transformer のどの部分で必要になるか、簡単な数値計算、記号・形状（shape）の読み方、短い透明な Python 実装、よくある誤解や高次元での「矢印」比喩の限界までを扱います。原著 Transformer に関する基本事実は Vaswani et al. 2017 に由来し、後年の変種とは区別して記述します。

勾配の最小の定義。1 変数の関数 L(θ) があるときの微分 dL/dθ は、θ を少しだけ変えたときの L の変化率を表します。すなわち小さな増分 Δθ に対して
ΔL ≈ (dL/dθ) · Δθ
が成り立つ（誤差は Δθ^2 程度）。複数のパラメータ θ = (θ1, θ2, …) の場合、勾配 ∇θ L は各成分の偏微分を並べたベクトルで、同じ形状（shape）を持ちます。多変数関数に対しては
ΔL ≈ ∇θ L · Δθ
（内積）となり、勾配は「損失を最も速く増やす方向」を示します。逆向き（−∇θ L）が局所的に損失を最も速く減らす方向であるため、勾配降下（gradient descent）は θ ← θ − η ∇θ L の形で用いられます（η は学習率）。

なぜ Transformer で必要か。Transformer の学習は損失（例えば教師ありの予測誤差や自己回帰の負対数尤度）を最小化する最適化問題です。Attention のクエリ／キー／バリューの重み行列、位置埋め込み、FFN（全結合層）の重み、LayerNorm のスケール項など、これら全てに対して損失が微分されます。特に注意すべき点は、注意機構の softmax、残差接続、層正規化などで勾配がチェーンルールを通じて伝播することです（勾配は入力→出力の順ではなく、出力の損失がどのように入力に影響するかを逆向きに伝える情報）。Vaswani et al. 2017 が示したアーキテクチャでは、勾配計算は誤差逆伝播（backpropagation）で行われ、勾配に基づいて確率的勾配降下（SGD や Adam などの変種）でパラメータが更新されます。以後の変種（学習率スケジューリングや正則化、最適化アルゴリズムの改良）は区別して扱うべきです。

数値例（スカラーの場合）。小見出し代わりに太字で示します。

**単一パラメータ例：L(θ) = (θ − 3)^2 の傾き（θ=1 と θ=4）**

関数を微分すると
dL/dθ = 2(θ − 3).
これを θ=1, 4 に代入します。
θ = 1 のとき dL/dθ = 2(1 − 3) = 2(−2) = −4.
θ = 4 のとき dL/dθ = 2(4 − 3) = 2(1) = 2.
意味の読み取り：θ=1 では傾きが −4 なので、θ を小さく増やす（Δθ>0）と ΔL ≈ −4·Δθ で損失が下がります。例えば Δθ = +0.1 のとき ΔL ≈ −0.4（損失が 0.4 減る）。一方 θ=4 では傾きが +2 なので小さく増やすと損失が増え、減らすと損失は下がります。勾配の符号が「増やすと損失が増える／減る」を教えてくれる局所的な情報です。

**二パラメータの小さな更新の計算**

関数を L(θ1, θ2) = (θ1 − 3)^2 + 0.5·(θ2 + 1)^2 とします（θ1 と θ2 は独立に寄与する簡単な例）。偏導関数は
∂L/∂θ1 = 2(θ1 − 3),
∂L/∂θ2 = 0.5·2(θ2 + 1) = (θ2 + 1).
点 θ = (θ1, θ2) = (1, 0) での勾配は
∇θ L = (2(1−3), 0+1) = (−4, 1).
学習率 η = 0.1 をとると勾配降下の更新は
θ_new = θ − η ∇θ L = (1, 0) − 0.1·(−4, 1) = (1 + 0.4, 0 − 0.1) = (1.4, −0.1).
変化後の損失差を近似すると ΔL ≈ ∇θ L · Δθ = (−4, 1) · (0.4, −0.1) = (−4·0.4) + (1·(−0.1)) = −1.6 − 0.1 = −1.7。元の損失は L(1,0)= (−2)^2 + 0.5·1^2 = 4 + 0.5 = 4.5、近似により新しい損失は約 2.8。実際に計算すれば誤差二次項で多少のずれがありますが、本質は勾配が局所の「どの方向にどれだけ変えれば損失がどれだけ変わるか」を線形に教えてくれる点です。

記号と shape の解読。θ はスカラー、ベクトル、行列など任意の形をとります。書き方のルールは次の通り簡潔に理解してください。θ（太字にすることも多い）はパラメータ全体、θ_i はその成分。L(θ) はスカラー（損失）。∇θ L は θ と同じ形状を持つテンソル（スカラーならスカラー、ベクトルならベクトル、行列なら行列）。線形代数的に扱う際は、勾配の形がパラメータの更新式と一致することが重要です（例えば重み行列 W の勾配は W と同じ形の行列）。多段の計算（行列積や要素ごとの活性化関数）ではヤコビ行列やテンソルの積が現れますが、実務では自動微分ライブラリが形状を保ちながら正しく扱います。

透明な短い Python コード（実行可能）。NumPy を用いて上の例をそのまま計算します。

```python
import numpy as np

def L_scalar(theta):
    return (theta - 3.0)**2

def dL_scalar(theta):
    return 2.0 * (theta - 3.0)

for theta in [1.0, 4.0]:
    print("theta =", theta, "L =", L_scalar(theta), "dL/dtheta =", dL_scalar(theta))

# 二変数例
def L_vec(theta):
    # theta is array-like [theta1, theta2]
    t1, t2 = theta
    return (t1 - 3.0)**2 + 0.5 * (t2 + 1.0)**2

def grad_L_vec(theta):
    t1, t2 = theta
    return np.array([2.0 * (t1 - 3.0), (t2 + 1.0)])

theta = np.array([1.0, 0.0])
grad = grad_L_vec(theta)
eta = 0.1
theta_new = theta - eta * grad
print("theta:", theta, "grad:", grad, "theta_new:", theta_new,
      "L before:", L_vec(theta), "L approx after:", L_vec(theta) + np.dot(grad, theta_new - theta))
```

よくある誤解。いくつか挙げて訂正します。
- 「勾配がゼロなら必ず最小値」：局所最大や鞍点でも勾配ゼロになります。ヘッセ行列（2 次導関数）で曲率を確認する必要があります。
- 「勾配の向きはグローバル最小へまっすぐ向かう」：勾配は局所線形情報のみを示すため、非凸空間では曲がりくねった経路をたどることになります。
- 「勾配の大きさが最小値までの距離の大小を示す」：大きさは損失の局所的勾配であり、曲率やパラメータのスケールに依存するので距離の見当をつけられません。
- 「学習率を同じにすれば全てのパラメータで同じ効果」：パラメータごとのスケールや勾配の分散が異なれば同じ η でも効果は異なります（これが Adam などの適応的最適化法の理由です）。

高次元での「矢印」比喩の限界。1 次元や 2 次元で勾配は矢印として直感できますが、実際のモデルは何百万から何十億の次元です。問題点は次の通りです。
- 可視化できない：高次元では矢印を描けず、直感は破綻します。方向の「直交性」や距離の意味が直感通りでないことが多い。
- 局所線形化の有効性：Δθ が小さい場合にのみ線形近似が有効で、ニューラルネットでは活性化関数や層の組合せで非線形性が強く働くことが多い。
- スケーリングと条件数：座標ごとにスケールが異なると、勾配はある方向で非常に小さく別の方向で非常に大きくなる。これをヘッセ行列の大きな条件数として理解すると良い。こうした場合、単純な勾配降下は効率が悪くなる。
- ノイズ：ミニバッチ勾配は確率的でノイズを含む。ノイズにより局所的に勾配が振動し、単純な矢印の意味が薄れる。
