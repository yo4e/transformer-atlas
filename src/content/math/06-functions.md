# Functions

**要点（概説）**
層（layer）は、入力を出力へ対応させる「パラメータ付き関数」です。訓練時にはそのパラメータがデータと目的関数に従って更新され、推論（inference）時にはパラメータは固定されて出力を生成します。Transformerでは埋め込み、クエリ／キー／バリューの線形射影（Q,K,V）、出力線形層、位置ごとのフィードフォワード（FFN）などが「層」にあたり、これらはすべてパラメータを持つ関数として振る舞います（Vaswani et al., 2017）。逆にReLUのような活性化関数は通常パラメータを持ちません（原著ではFFNにReLUが用いられています。後年の変種ではGELUなどが使われることがあります—後年の変更点は明示して区別してください）。

**なぜTransformerのどの箇所で必要か**
- 埋め込み層（token embedding, positional embedding）: 単語IDを連続ベクトルへ写像するパラメータ付き関数。
- マルチヘッド注意の線形射影（Q,K,V）と出力線形層: 入力ベクトルを別の表現空間へ線形変換する層。これが注意重み計算やヘッド間の情報のやり取りを可能にする。
- 位置ごとのFFN（原著では2層の線形＋ReLU＋線形）: 各位置で独立に別の表現へ写像する非線形層。
これらはすべて「入力を別表現へ写す関数」であり、訓練でその写し方（パラメータ）を学習します。

**最小の定義**
層 L はパラメータ θ を持つ関数 fθ で、入力 x を出力 y へ写す: y = fθ(x)。
- 訓練時: θ ← θ − η ∇θ Loss(fθ(x), target) のように更新される（最適化アルゴリズムに依存）。
- 推論時: θ は固定され、同じ x に対して必ず同じ y を返す（決定的であるか否かはドロップアウト等の有無によるが、推論では通常無効にする）。

**具体的な数値例（省略せず計算）**
同じ入力 x を三つの異なる関数で写してみます。入力は2次元ベクトル x = [3, −1] とします。

1) f(x) = 2x + 1（要するに各成分に対して2倍して1を足す）
- まず成分ごとに計算:
  - 2×3 + 1 = 7
  - 2×(−1) + 1 = −2 + 1 = −1
- 結果: f(x) = [7, −1]

2) ReLU(x)（各成分を0未満で切り捨てる）
- ReLU(3) = max(0, 3) = 3
- ReLU(−1) = max(0, −1) = 0
- 結果: ReLU(x) = [3, 0]

3) xW（行ベクトル x に行列 W を掛ける）
- ここで W を 2×2 行列とする。例として
  W = [[1, 2],
       [0, −1]]
  とおく。
- 行列積 xW を計算:
  - 第1成分: 3×1 + (−1)×0 = 3 + 0 = 3
  - 第2成分: 3×2 + (−1)×(−1) = 6 + 1 = 7
- 結果: xW = [3, 7]

まとめると、同じ入力 x = [3, −1] が三つの関数によって別の表現へ写される:
- f(x) = [7, −1]
- ReLU(x) = [3, 0]
- xW = [3, 7]

この例は、層が「どう写すか（パラメータ）」によって出力が大きく変わることを示します。f の係数や W の値が訓練で変わると、同じ入力が異なる最終表現へ変化します。

**記号と shape（形状）の読み方**
- ベクトル x ∈ R^d は次元 d の表現（トークン埋め込みや隠れ状態）を表します。シーケンス全体なら X ∈ R^{T×d}（時刻数 T × 次元 d）。
- 行列 W ∈ R^{d_in × d_out} は d_in 次元を d_out 次元へ線形写像する重み。行列積 xW は（1×d_in）×（d_in×d_out）→（1×d_out）となります。
- バイアス b ∈ R^{d_out} は線形変換の後に足される列ベクトル。
- 活性化関数（ReLUなど）は形状を保ちつつ要素ごとに非線形変換を行います。
Transformer の典型的な形状例（原著）: 埋め込みや隠れ次元 d_model、FFN の中間次元 d_ff（通常 d_ff > d_model）。

**透明な短いPythonコード（実行可能な例）**
以下は上の数値例をそのまま計算するNumPyコードです。実際に動きます。

```python
import numpy as np

x = np.array([3, -1])            # 入力ベクトル
fx = 2 * x + 1

# 2) ReLU(x)
relu = np.maximum(0, x)

# 3) xW
W = np.array([[1, 2],
              [0, -1]])
xW = x.dot(W)  # または np.matmul(x, W)

print("x =", x)
print("f(x) = 2x + 1 ->", fx)
print("ReLU(x) ->", relu)
print("xW ->", xW)
```

出力は:
x = [ 3 -1]
f(x) = 2x + 1 -> [ 7 -1]
ReLU(x) -> [3 0]
xW -> [3 7]

**よくある誤解**
- 「層＝パラメータを必ず持つ」：誤り。活性化関数（ReLU等）は通常パラメータを持たない層的操作です。層の中にはパラメータを持つもの（線形、埋め込み、LayerNormのスケールとシフト）と持たないもの（活性化、ソフトマックス）があります。
- 「訓練でも出力は常に同じ」：ドロップアウトのような訓練時のみ動作する確率的操作があるため、訓練時は出力が揺らぎます。推論時は確率的操作を無効にして決定的にするのが一般的です。
- 「xW と Wx は同じ」：行列の掛け算は形状に依存します。行ベクトル x（1×d）に W（d×k）を掛けるのと、W に列ベクトルを掛けるのは文脈が異なります。形状を常に意識してください。
- 「ReLUが学習する」：ReLU 自体に学習するパラメータはありません（ただしLeaky ReLUなど一部の活性化は係数を持つ場合があります）。

**読者が説明できること（学習目標）**
- 「層」をパラメータ付き関数として定義し、訓練と推論でパラメータがどう扱われるか説明できる。
- 同じ入力が f(x)=2x+1、ReLU、xW のように異なる層でどのように別表現へ写るか手計算で示せる。
- Transformer におけるどの部分がパラメータ付き層で、どの部分が非パラメータ操作かを挙げられる（例えばQ/K/Vの線形射影はパラメータ付き、ReLUは非パラメータ）。
- 行列とベクトルの形状（shape）が積でどう決まるか説明できる。
