# Probability distributions

トランスフォーマーの理解で頻出する「分布（probability distribution）」について、数学の前提なしに平易にまとめます。本稿は「分布を非負で合計1の重み列として見る」観点を中心に、attentionの重みと次トークン確率の類似点と相違点を具体例で示します。原著のTransformerに関する事実は Vaswani et al. 2017 に従い、後年の変種とは区別して説明します。

**なぜトランスフォーマーで分布が必要か（どの箇所で使われるか）**
トランスフォーマーでは大きく二箇所で「重みが非負で合計1」になる正規化が使われます。ひとつは自己注意（self-attention）における「注意重み（attention weights）」、もうひとつはモデルの最終出力に対する「次トークン確率（next-token probability）」です。前者はある位置（クエリ）が入力系列のどの位置（キー）をどれだけ参照するかを表す重み列で、値ベクトル（value）を重み付き合成して出力を作ります。後者は語彙の各トークンが次に出現する確率を表し、生成や学習（クロスエントロピー損失）に直接使われます。両者は通常softmaxで正規化されるため同じ数学的性質（非負・和が1）を持ちますが、用途と解釈は異なります。

**最小の定義**
有限集合上の分布とは、要素ごとの重み w_i ≥ 0 を並べ、合計 Σ_i w_i = 1 となるようにした列（ベクトル）です。softmax は任意の実数列 z_i を非負にし和1にする（正規化する）代表的な関数で、softmax(z)_i = exp(z_i) / Σ_j exp(z_j) です。

**記号とshapeの解読（簡潔）**
典型的なトランスフォーマーの記法を簡単に示します（バッチやヘッドを省略した単純形）：
- 入力系列長 L、埋め込み次元 D。
- Q（クエリ）: shape (L, D_q)、K（キー）: shape (L, D_k)、V（バリュー）: shape (L, D_v)。
- 注意重み行列 A = softmax(Q K^T / sqrt(D_k)) は shape (L, L)（各クエリ位置ごとにL個の重み）。各行が分布（非負・和1）。
- 出力は A V（行列積）、各クエリは値ベクトルの重み付き和を受け取ります。
一方、語彙に対する次トークン確率は、最終隠れ状態 h（shape (D) あるいは (L,D)）に線形変換 W_o を適用して得たロジット列 logits（長さ = 語彙サイズ |V|）に対して softmax をとったものです。結果は長さ |V| の分布です（各インスタンスごとに一つの分布）。

**数値例（必須）**
ここで必ず提示する数値例を手順を追って示します。与えられた注意重みベクトル p = [0.5, 0.3, 0.2] を使い、重み付き value の計算と、語彙三個の次トークン分布としての解釈を並べて比較します。数の計算は遅くても構いません。重要なのは「それぞれの数が何を表しているか」です。

まず、valueベクトルを次のように定めます（各値は D_v = 2 次元ベクトルとする）:
v1 = [1.0, 0.0]
v2 = [0.0, 1.0]
v3 = [1.0, 1.0]

注意重み p = [0.5, 0.3, 0.2] をこれらに掛けて合成すると、
weighted_sum = 0.5 * v1 + 0.3 * v2 + 0.2 * v3
各成分ごとに計算すると、
第一成分 = 0.5*1.0 + 0.3*0.0 + 0.2*1.0 = 0.5 + 0 + 0.2 = 0.7
第二成分 = 0.5*0.0 + 0.3*1.0 + 0.2*1.0 = 0 + 0.3 + 0.2 = 0.5
従って合成出力は [0.7, 0.5] になります。ここで p は「3つの位置（あるいは3つの他のトークン）に対する相対的な重み」を意味し、その重みで値ベクトルを加重和しています。重みは分布なので負の重みや和が1を超えることはありません。

同じ p = [0.5, 0.3, 0.2] を「語彙サイズ3の次トークン確率」として解釈する場合、これは「語彙のトークン a,b,c が次に来る確率がそれぞれ 0.5,0.3,0.2 である」と読みます。生成時にはフル確率分布からサンプリングするか、確率が最大のトークン（ここなら a）を選びます。学習時にはモデルの出力（上の分布）と正解トークンの1-hot分布を比べてクロスエントロピー損失を計算します。

要点の比較：
- attentionのp: 「どの位置の情報をどれだけ取り込むか」を示す重み。実際の計算は値ベクトルの決定論的な加重平均。
- 次トークンのp: 「次にどの語が出現するかの不確実性」を表す確率分布。生成や損失に直接用いる。

**透明な短いPythonコード（実行可能）**
以下は上の数値例をそのまま計算する短いPythonコードです（標準ライブラリだけで動きます）。

```python
p = [0.5, 0.3, 0.2]
v1 = [1.0, 0.0]
v2 = [0.0, 1.0]
v3 = [1.0, 1.0]
values = [v1, v2, v3]

weighted = [sum(p_i * v_i_j for p_i, v_i_j in zip(p, col)) for col in zip(*values)]
print("weighted sum:", weighted)  # => [0.7, 0.5]

# 次トークン分布としての解釈（サンプリング例）
import random
random.seed(0)
tokens = ['a', 'b', 'c']
def sample_token(probs):
    r = random.random()
    cum = 0.0
    for t, p in zip(tokens, probs):
        cum += p
        if r < cum:
            return t
    return tokens[-1]

print("sampled token:", sample_token(p))
```

意味を保つために、これは実際に value の加重和を計算し、確率分布からのサンプル例も示しています。

**よくある誤解**
- 「attentionの重みは『重要度の確率』で、必ず解釈可能な説明になる」：attentionは値ベクトルを合成するための係数であり、解析上の「説明変数」や因果的な重要度を直接示すわけではありません（Jain & Wallace 2019 の指摘）。
- 「softmaxが出す分布は常に一部だけを強く選ぶ（スパース）」：温度パラメータやロジットの差で分布の鋭さは変わります。必ずしも極端にスパースになるわけではありません。
- 「attentionの重みと次トークン確率は同じ意味を持つ」：数学的には同じ性質（非負・和1）を持つが、前者は加重平均の係数、後者は生成確率という用途上の違いがあります。
